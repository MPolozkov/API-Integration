**Чтобы запустить проект**

Проект на FatAPI.

Виртуальное окружение poetry.

Реализован вход на сайт через Oauth2.0 и получение токена.

Нужно в терминале написать uvicorn main:app --reload

Для ключей есть фаил .env.example

Второй ендпоинт служит как возврат кода, с возврата подтверждения.

При зпуске первоно эдпоинта GET, возврощает ссылку по которой нужно перейти в браузере. 
Подтвердить вход и скопировать код из адресной строки без code и =.
Код вставить в ендпоинт с POST запросом. Вернуться данные с токеном.
